# KMC Scales and Systems website

Static website for KMC Scales and Systems. It uses plain HTML, CSS, and JavaScript and has no build step or package dependencies.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Publish with GitHub Pages

1. Push this project to the `easy-scales` GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
4. Once GitHub Pages finishes publishing, the site will be available at <https://kineticmeasure.online/>.

The sitemap and canonical links use that GitHub Pages URL. If the repository name, GitHub account, or public site URL changes, update `sitemap.xml`, `robots.txt`, and the canonical links in the HTML pages.
